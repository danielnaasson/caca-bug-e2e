# BUG-002: o botão lateral promete avançar, mas encerra a fase

| Campo | Valor |
|---|---|
| Severidade | S3 (Médio): fluxo secundário com contorno |
| Prioridade | P2 |
| Status | **Aberto** |
| Teste | `CT-NAV-005` (marcado com `it.skip` até a correção) |

## Passos

1. Começar o ciclo.
2. Clicar em **Encerrar ciclo de teste**.
3. Clicar em **Próximo build**.
4. Olhar o botão lateral na fase 2.

## Resultado esperado

O botão volta a dizer **Encerrar ciclo de teste**.

## Resultado obtido

O botão continua dizendo **Ir para o próximo build**. Quem clica esperando só avançar encerra a fase, perde o tempo restante e os bugs ainda não reportados contam como "escaparam para produção".

## Causa provável

`endLevel()` troca o texto do botão, e `startLevel()` não o restaura. Só o botão **Testar de novo** faz isso.
