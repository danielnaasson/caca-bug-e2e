# BUG-001: a tela de abertura não fecha e o jogo não começa

| Campo | Valor |
|---|---|
| Severidade | S1 (Crítico): sistema inutilizável |
| Prioridade | P0 |
| Status | **Corrigido** |
| Achado por | Primeira execução da suíte, em `CT-INICIO-003` |
| Ambiente | GitHub Pages, Electron via Cypress 15.21.1; reproduzido também no navegador do app |

## Passos

1. Abrir o jogo publicado.
2. Clicar em **Começar o teste**.

## Resultado esperado

A abertura fecha e a fase 1 fica disponível.

## Resultado obtido

A abertura continua cobrindo a tela e nada mais pode ser clicado.

## Causa

O JavaScript escondia a camada com o atributo `hidden`, mas o CSS `.overlay{display:flex}` tem prioridade sobre ele. No ambiente original (Artifact) havia uma regra global que escondia esses elementos, então o defeito só apareceu ao publicar em outro lugar.

```text
#ov.hidden = true
getComputedStyle(#ov).display = "flex"
```

## Correção

Adicionada a regra `[hidden]{display:none!important}` em `caca-bug/index.html`.

## O que isso ensina

Abrir a página e receber HTTP 200 não prova que ela funciona. A checagem manual feita na publicação só confirmou que a página carregava; o defeito apareceu no primeiro clique automatizado.
